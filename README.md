# Right Nav Panel Customizer (右ナビパネル改変)

SillyTavernの右側「キャラクター管理」パネルのキャラクター一覧を、
グリッド表示・大きめのサムネイル表示にカスタムする拡張機能です。

併せて、各キャラクターの`<name>_ext.json`内の`image_display_extension.thumbnail`
に指定された画像があれば、一覧のアバター画像をその画像に差し替えます。
（`thumbnail`が未設定、または`_ext.json`自体が存在しない場合は、通常のアバター画像がそのまま表示されます）

## 依存関係

このJSONファイル形式は `stj_editor` 拡張機能で作成することを想定しています。

## インストール方法

1. SillyTavernの拡張機能パネルを開く
2. 「拡張機能をインストール」をクリック
3. このリポジトリのURLを貼り付けて保存
